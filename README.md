# Oversabi Stitches

A premium Nigerian fashion atelier website built with Next.js 14, Sanity CMS, and Tailwind CSS.

## Features

- **Product Catalog**: Browse collections with detailed product pages
- **Bespoke Services**: Measurement booking and consultation flow
- **Fabric Library**: Explore traditional Nigerian textiles
- **WhatsApp Integration**: Direct inquiry and ordering
- **Sanity Studio**: Embedded CMS for content management

## Tech Stack

- Next.js 14 (App Router)
- React 18
- TypeScript
- Tailwind CSS
- Sanity CMS
- Lucide Icons

## Getting Started

1. Clone the repository
2. Copy `.env.example` to `.env.local` and fill in your credentials
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000)

## Project Structure

```
app/              # Next.js App Router
components/       # React components
lib/             # Utilities and Sanity client
sanity/          # Sanity schemas and configuration
public/          # Static assets
```
